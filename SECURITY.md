# Security Policy

## Reporting a problem

Please do **not** open a public issue, pull request or Discord post for a
security problem.

Report it privately through GitHub: open the **Security** tab of this
repository and choose **Report a vulnerability**. Include what you found, the
steps to reproduce it, and what an attacker could do with it.

We will reply as soon as we can, fix confirmed problems before talking about
them in public, and credit you if you want.

## What counts

- Ways for a regular Discord member to make the bot crash, spam, ping
  everyone, or post where they should not.
- Ways around the permission checks on any command or button.
- Any secret (token, password, key) or private server address found in this
  repository or its history.

## Never include

Real tokens, passwords, server addresses or player data in a report. If you
found one, tell us where it is, not what it is.
